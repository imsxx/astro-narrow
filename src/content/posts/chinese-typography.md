主题的排版层是从上游原样搬过来的，但中文和英文的行高、标点、段距需求不同。这篇文章用来看实际效果。

## 正文段落

一段正常长度的中文段落，用来观察行高和字距。中文没有词间空格，行高偏小会显得拥挤，偏大又会打断阅读节奏。理想状态下，读者不应该注意到行距的存在。

混排时也要看：`inline code`、**加粗**、*斜体*、[链接](https://astro.build)，以及英文单词 Astro 与中文之间的间距。

> 引用块用来放一段旁注。它的左边框颜色来自主题的 border 变量。

## 代码块

```ts
export function readingTime(body: string): number {
  return Math.max(1, Math.round(wordCount(body) / 300))
}
```
